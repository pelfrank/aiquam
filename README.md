# AIQUAM++

Prediction system for *Escherichia coli* contamination in farmed mussels, based on hydrodynamic data from the **WCM3** (Water Column Model 3D) numerical model.

---

## Overview

AIQUAM++ trains four classification models on time series of suspended matter concentration, extracted from WCM3 NetCDF files. Each prediction assigns a shellfish farming site to one of four contamination classes defined by European regulations:

| Class | Range (MPN/100g) | Meaning |
|-------|------------------|---------|
| 0 | 0 – 67 | Zone A — direct sale allowed |
| 1 | 67 – 230 | Zone B — depuration required |
| 2 | 230 – 4600 | Zone C — extended relaying required |
| 3 | > 4600 | Out of norm |

## Configuration

All parameters are in **`config.ini`**, split into two sections:

### `[training]`

| Parameter | Default | Description |
|-----------|---------|-------------|
| `DATASET_DIR` | `dataset` | Root directory for CSV files |
| `DATASET_YEARS` | `2023, 2024` | Years to include |
| `HOURS` | `72` | Length of the temporal window (hours) |
| `N_CLASSES` | `4` | Number of classes |
| `MODELS_DIR` | `models` | Model output directory |
| `RANDOM_SEED` | `42` | Seed for reproducibility |
| `TEST_SIZE` | `0.3` | Test set fraction |
| `KNN_DTW_N_NEIGHBORS` | `2` | Neighbors for KNN+DTW |
| `KNN_DTW_WARPING_WINDOW` | `5` | DTW warping window |
| `KNN_N_NEIGHBORS` | `2` | Neighbors for KNN sklearn |
| `CNN_EPOCHS` | `60` | CNN training epochs |
| `CNN_BATCH_SIZE` | `72` | CNN batch size |
| `RESNET_EPOCHS` | `100` | ResNet training epochs |
| `RESNET_N_FEATURE_MAPS` | `32` | ResNet feature maps |

### `[inference]`

| Parameter | Default | Description |
|-----------|---------|-------------|
| `URL` | `https://data.meteo.uniparthenope.it/opendap/wcm3/d03/archive/` | OPeNDAP base URL |
| `START` | `1` | First previous hour to download |
| `END` | `72` | Last previous hour (must match `HOURS`) |
| `AREAS_FILE` | `areas.geojson` | GeoJSON of farming areas |
| `OUTPUT_DIR` | `output` | Directory for output NetCDF files |
| `NC_ROOT` | *(empty)* | Local directory with pre-downloaded NetCDF files (optional) |

> If `NC_ROOT` is set, `prediction.py` looks for files on disk first; if not
> found, it downloads them via OPeNDAP and saves them automatically in the same
> subdirectory structure (`NC_ROOT/YYYY/MM/DD/`).

## Workflow

### 1. Training

```bash
python training_new.py
```

Reads CSV files from `dataset/<year>/`, builds feature vectors (`h_-71 … h_+00`),
applies SMOTE on minority classes, and trains four models:

- **KNN + DTW** (`models/KNN_DTW.pkl`) — k-nearest neighbors with Dynamic Time Warping
- **KNN sklearn** (`models/KNeighborsClassifier.pkl`) — baseline with Euclidean distance
- **Multi-scale CNN** (`models/CNN.keras`) — three branches with kernels 3, 5, 11
- **ResNet 1D** (`models/ResNet.keras`) — three residual blocks

For each model, a confusion matrix and training history plot are saved in `models/`.

### 2. Inference on NetCDF Grid

```bash
python prediction.py <YYYYMMDDZHHMM>
# example:
python prediction.py 20261031Z0000
```

For the given date/time:
1. Loads farming areas from `areas.geojson`
2. Reads the lat/lon grid from the OPeNDAP server
3. For each previous hour (from `START` to `END`) downloads the surface concentration
4. For each grid pixel inside a farming area, builds the 72-feature vector
5. Classifies with KNN sklearn and writes the predicted class to the output NetCDF

Output: `output/aiq3_d03_<datetime>.nc.nc4`

A CSV file with a `DATA PRELIEVO` column can also be passed:

```bash
python prediction.py misurazioni.csv
```

### 3. Prediction from CSV Sample

`predict_csv.py` supports two sub-commands: **`file`** (single CSV) and **`dir`** (whole directory).

#### Single file

```bash
python predict_csv.py file <input.csv> [output.csv]
# shorthand (backward-compatible):
python predict_csv.py <input.csv> [output.csv]

# examples:
python predict_csv.py file sample.csv
python predict_csv.py file sample.csv sample_predicted.csv
```

Reads a CSV in the training format (columns `h_-71 … h_+00`) and writes
a new CSV with the same columns plus:

| Column | Content |
|--------|---------|
| `pred_knn_dtw` | KNN+DTW predicted class |
| `pred_knn` | KNN sklearn predicted class |
| `pred_cnn` | CNN predicted class |
| `pred_resnet` | ResNet predicted class |
| `predicted_class` | **Majority vote** across all 4 models |

If `output.csv` is not specified, the file is saved next to the input
with the suffix `_predicted.csv`.

#### Directory (batch)

```bash
python predict_csv.py dir <input_dir> [output_dir] [--recursive] [--skip-errors]
```

Processes every `*.csv` file found in `<input_dir>` (files already ending in
`_predicted.csv` are skipped automatically). Models are loaded only once and
reused across all files.

| Option | Description |
|--------|-------------|
| `output_dir` | Directory where results are written (default: same as input, `_predicted.csv` suffix) |
| `--recursive` | Also search CSV files in sub-directories |
| `--skip-errors` | Continue processing if a file fails; errors are listed at the end |

```bash
# examples:
python predict_csv.py dir dataset/2024/
python predict_csv.py dir dataset/2024/ results/2024/ --recursive
python predict_csv.py dir dataset/ results/ --recursive --skip-errors
```

---

## CSV Sample Format

Each row represents one farming sample. Expected columns:

- `h_-71`, `h_-70`, …, `h_-01`, `h_+00` — surface concentration in the 72 hours preceding the sampling date
- `target` — contamination class (0–3); present in training CSVs, optional for inference
